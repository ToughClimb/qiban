# 在手机上开始用栖伴

下载 `Qiban-Android-test.apk`。这是预览测试包，使用临时测试签名；请按 Android 的提示决定是否允许安装。不同预览包的签名可能不同，无法保证直接升级。卸载会删除本机聊天、角色、头像和聊天图片；先导出需要保留的角色 JSON。本版没有完整聊天备份恢复功能。

打开后选“先用演示聊天”，再选一位虚拟伙伴。演示回复是预设示例，界面会一直标明，不需要账号或密钥。每位伙伴的聊天分别保存在手机上。换伙伴会取消等待中的回复；发送失败后可以重试或编辑。“清空聊天”只清空当前伙伴，需确认。

想用自己的 AI 服务，打开“连接与数据”，填写服务方给出的公开 HTTPS 地址。API 密钥在手机原生输入框填写，不要把它发到聊天里。连接检查只读取模型列表；实际对话可能由服务方收费。多个模型时请选一个，没有模型列表时按服务方说明填写模型名称。“记住密钥”默认关闭；勾选后使用 Android 加密保存在本机。单独删除密钥会保留聊天。设置里的“外观”可以修改主题色。

输入框旁的回形针可选择本机 PNG、JPEG 或静态 WebP。选图只在手机上处理和预览，点“发送”后才会交给已连接的服务；也可以只发图。图片聊天目前需要支持图片的 DeepSeek Flash 服务，演示模式不识别图片。一条消息最多一张图，原文件最多 5 MiB、最长边 4096 像素；栖伴另存缩小并去除附加元数据的副本，不修改原文件。每次回复只读取最近三张图，较早的图仍保留在聊天中，并显示本次未读取的提示。待回复的图片丢失时，可以编辑为文字或重新选图。

“管理角色”可以新建、复制、编辑或导入 Tavern V1/V2 JSON 角色。先检查预览，再确认保存。编辑保留原始扩展字段，但工具、脚本和模型配置不会生效。导出只包含角色 JSON，不包含聊天或图片。删除角色会删除它的聊天和本机图片。

使用 AI 时，近期聊天、角色设定和本次需要的图片会发送给你填写的服务。栖伴不提供内置付费账户。“删除所有本机数据”会删除角色、备份、聊天、图片、连接设置和主题偏好，无法恢复。手机上的系统文件选择器、键盘和最低 Android 版本仍需人工试用；API35 模拟器通过不等于所有手机都已验收。
