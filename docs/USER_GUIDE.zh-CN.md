# 开始用栖伴

打开后可以先选“先用演示聊天”。演示回复是预设示例，页面会一直标明，不需要账号或密钥。选一位虚拟伙伴，写下消息，按 Enter 发送；Shift + Enter 换行。使用中文输入法时，确认候选字不会同时发送消息。

想用自己的 AI 服务，在“连接与数据”里填写服务方给出的 HTTPS 地址和 API 密钥。这里的密钥只用于连接服务，不要发到聊天里。通常可以填写服务根地址、`/v1` 地址，或完整的 `/chat/completions` 地址。只支持公开 HTTPS 服务，不支持局域网、本机服务和需要跳转的地址。

连接检查会读取模型列表。DeepSeek 会选默认聊天模型；其他服务只有一个模型时自动使用，多个模型时请选一个。没有模型列表时，按服务方说明填写模型名称。连接检查不发送聊天，但实际 AI 对话可能由服务方收费。栖伴没有内置付费账户，也不会自动重试发送。

“记住密钥”默认关闭。关闭时退出应用就会忘记密钥；勾选后由 Windows 加密保存在本机。你可以单独删除密钥而保留聊天。加密不能防止已经以同一 Windows 用户身份运行的软件访问它。

每位伙伴的聊天分别保存在本机。换角色会取消正在等待的回复；没有回复的消息可以重试或编辑。“清空聊天”只清空当前角色，需确认。读取或保存失败会显示提示，请先检查磁盘并备份数据。栖伴不会上传到自己的服务器；使用 AI 时，近期聊天和角色设定会交给你填写的服务。

## 写一个自己的角色

点“管理角色”，选择“写一个新角色”或“复制并编辑”现有伙伴。写清楚名字、背景、性格、情境、开场白和对话示例，保持简短、具体。检查预览，再确认保存。内置角色不会被覆盖。自定义角色可以编辑、删除或导出原始 JSON；删除会同时删除这个角色的聊天。

也可以从本机导入 Tavern V1/V2 JSON 角色文件。先查看不支持的字段提示，再保存。图片角色卡、自动工具、系统提示替换、世界书和扩展功能不生效；原始 JSON 会保留这些字段供导出。宏和 HTML 按文字显示，不会执行。

“打开角色文件夹”能找到自己的文件。最多加载 20 个自定义角色；编辑时保留原文件名，它决定聊天属于谁。界面编辑会保留最近五份旧 JSON 备份。

## 请 AI 助手帮忙

先关闭栖伴。备份 `%APPDATA%\Qiban` 中的 `cards` 文件夹和 `history.json`。把需要修改的 JSON 文件给可信赖的助手，说明想怎样调整角色；请它保留原格式和文件名，只修改角色文字字段。不要分享密钥、`connection.json` 或不愿分享的聊天。

修改后打开栖伴，在“管理角色”中点“重新加载角色文件”。已有聊天不会自动清空。如果希望按新设定重新开始，可单独清空当前角色的聊天。

恢复时关闭应用，把备份的 `cards` 和 `history.json` 放回同一个数据目录，再打开应用。请勿修改安装目录或 `app.asar`。升级使用同一数据位置，角色和聊天会保留。设置里的“删除所有本地数据”会删除角色、备份、聊天和连接设置，无法恢复；先导出或备份。

当前安装包尚未签名，Windows 可能提示未知发布者。自动更新尚未配置。实际普通用户安装、升级和卸载清理仍需验收。
